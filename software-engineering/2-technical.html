Python

Basic

  • Explain whether Python pass by value or reference
    • Pass by value - copy of variable value (stored in a new location in memory) is passed to function, so updates does not impact original variable
    • Pass by reference - memory address of variable is passed to function, so updates impacts original variable
    • Pass by object reference - function gets copy of variable but that copy points to same object in memory. If mutable object is passed, it will be modified, if immutable object is passed, new object will be created
  • Explain Global Interpreter Lock
    • Python interpreter only allows one thread to execute Python bytecode
    • There will be no deadlock due to a single thread
    • Can slowdown CPU bound exeuctions
    • Using multi-core environment can be a solution

Built-in types

  • Explain difference between list, tuple, dictionary, set
    • List - ordered, duplicates, mutable
    • Tuple - ordered, duplicates, immutable
    • Dictionary - unordered, no duplicates (keys), mutable
    • Set - unordered, no duplicates, mutable
  • Explain difference between sort and sorted
    • sort - sort in place
    • sorted - creates new object that is sorted

Class and object

  • Explain class variable and instance variable
    • Class variable - shared by methods within the class
    • Instance variable - used within methods, self keyword
  • Explain method overloading and method overriding in Python
    • Method overloading - same signiture but different arguments within the same class
    • Method overriding - same signiture and arguments between parent and child class
  • Explain difference between class method and static method
    • Class method - access and modify class variables, @classmethod
    • Static method - utility functions inside the class, @staticmethod
  • Explain encapsulation, inheritance, polymorphism
    • Encapsulation - hiding information within the class via private variable and method
    • Inheritance - let child class to re-use non-private methods from parent class
    • Polymorphism - same form but different implementation (method overloading and method overriding)
  • Explain operator overloading
    • Change implementation of operator
  • Explain dynamic typing

# Create is O(1) knowing the lottery and owner number
# Delete is O(1) knowing the lottery number   
# Pick winner
#   Randomly generate 7 numbers - O(1)
#   Search these numbers in the dictionary - O(1)
#   Return value of dictionary, which is the owner

class Lottery:

    def __init__(self):
        self.lotteries = defaultdict(int)

    def create(numbers, owner):
        self.lotteries[numbers] = owner

    def delete(numbers)
        del self.lotteries[numbers]

    def pick_winner():

        winning_number = []
        for _ in range(7):
            winning_number.append(random.randint(1,99))

        winning_number = tuple(winning_number)

        return self.lotteries[winning_number]
